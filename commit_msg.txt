Sprint 143: Pick and Place (PnP) Export

Why:
Board assembly requires Pick and Place centroid data to program automated assembly machines. We need to export component positions and side (Top/Bottom).

Changed:
- Added `src/ccad_core/pnp_export.cpp/hpp` to compute centroids from pad bounding boxes.
- Added `exportPnpCommand` to `src/ccad_cli/project_commands.cpp`.
- Updated `src/ccad_cli/app.cpp` to map `ccad pcb export-pnp`.
- Added unit tests in `tests/test_pnp_export.cpp`.
- Updated `CMakeLists.txt` for the new module.
- Updated `progress.md` and `implemented-features.md`.

Behavior:
- Running `ccad pcb export-pnp --file project.json --output pnp.csv` generates a CSV file with Designator, Value, PosX, PosY, and Side.

Verification:
- `ctest -R pnp_export` verifies centroid calculation from pad coordinates.
- `ctest -R cli` verifies CLI integration and binary builds.

Demo:
- Test runner output acts as the proof. (No visual GUI changes for this sprint).
