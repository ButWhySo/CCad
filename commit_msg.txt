Sprint 144: Excellon Drill Export

Why:
Bare-board fabrication requires drill files to dictate via and through-hole sizes and locations. The standard format is Excellon NC Drill.

Changed:
- Added `std::optional<Length> drill` to `Pad` in `src/ccad_core/model.hpp`.
- Updated `src/ccad_core/serialize.cpp` to persist and load pad `drill_nm`.
- Updated `src/ccad_cli/pcb_commands.cpp` to forward `footprint_pad.drill` to board pads on placement.
- Added `src/ccad_core/drill_export.cpp/hpp` to emit Excellon format from vias and pads.
- Added `exportDrillCommand` to `src/ccad_cli/project_commands.cpp`.
- Updated `src/ccad_cli/app.cpp` to map `ccad pcb export-drill`.
- Added unit tests in `tests/test_drill_export.cpp`.
- Updated `CMakeLists.txt` for the new module.
- Updated `progress.md` and `implemented-features.md`.

Behavior:
- Running `ccad pcb export-drill --file project.json --output pnp.drl` generates an Excellon file containing tool sizes (INCH) and coordinates for all drilled geometries.

Verification:
- `ctest -R drill_export` verifies Excellon formatting and tool assignment.
- `ctest -R cli` verifies CLI integration and binary builds.

Demo:
- Test runner output acts as the proof. (No visual GUI changes for this sprint).
