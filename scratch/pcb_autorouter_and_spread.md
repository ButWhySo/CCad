# KiCad Source Walk: Autorouter and Footprint Spreading (Batch 8)

## Overview
This batch enters the `pcbnew/autorouter/` directory, focusing on the legacy auto-placement engine and the footprint spreading utilities.

- **Files**:
  - `pcbnew/autorouter/ar_autoplacer.cpp`, `.h`
  - `pcbnew/autorouter/ar_matrix.cpp`, `.h`

  - `pcbnew/autorouter/spread_footprints.cpp`, `.h`

## 1. Routing Matrix & Cost Fields (`ar_matrix.cpp`, `ar_matrix.h`)
- **`AR_MATRIX`**: Represents the physical board area discretized into a grid of `MATRIX_CELL` (occupancy/type) and `DIST_CELL` (cost/distance).
- The matrix is a fundamental data structure for spatial algorithms. It handles rasterization of PCB shapes (`TracePcbShape`), pads (`PlacePad`), and footprint keepouts.
- Cells can be marked as free (`CELL_IS_ZONE`), occupied by other footprints (`CELL_IS_MODULE`), or blocked by holes/edges (`CELL_IS_HOLE`, `CELL_IS_EDGE`).

## 2. Legacy Auto-Placer (`ar_autoplacer.cpp`, `.h`)
- **`AR_AUTOPLACER`**: A heuristic-based placement engine that evaluates potential footprint locations using a cost function.
- **Cost Function**: Evaluates a combination of ratsnest length (manhattan/hypotenuse approximations) and keepout violations. The "best" position minimizes this combined score.
- **Workflow**:
  1. Rasterize board outline and existing obstacles into the `AR_MATRIX`.
  2. Pick the most critical unplaced footprint (sorted by complexity/pad count/ratsnest connections).
  3. Scan the grid to find the optimal valid spot minimizing ratsnest cost.

## 3. Tool Interface (`autoplace_tool.cpp`, `.h`)
- A standard KiCad `PCB_TOOL_BASE` that wraps the `AR_AUTOPLACER`.
- Exposes actions like `autoplaceSelectedComponents` and `autoplaceOffboardComponents`.
- Interfaces with the `BOARD_COMMIT` system to push undoable placement states.
- Triggers a callback to refresh the GUI canvas during placement.

## 4. Footprint Spreading (`spread_footprints.cpp`, `.h`)
- Uses `rectpack2D`, a 2D bin-packing algorithm, to spread out overlapping footprints (typically after a netlist import where they all spawn at `0,0`).
- **Grouping**: Attempts to group footprints by hierarchical sheet (from the schematic) to preserve logical clusters.
- The algorithm calculates optimal bounding boxes for these groups and packs them into a larger target area outside the main board.

## CCad Analogue
- CCad aims to be an LLM-native CAD tool. While a discretized routing matrix (`AR_MATRIX`) is computationally simple and robust, modern CAD often relies on continuous spatial indices (like R-Trees or KD-Trees) for collision detection.
- The concept of footprint spreading (bin packing) is highly relevant for initial placement passes generated by the LLM agent.
- `AR_AUTOPLACER` is a rudimentary procedural heuristic. In CCad, we would expect the LLM or an external solver (like a SAT solver or constraint programmer) to drive the placement, making the procedural heuristic less relevant, though the cost-function evaluation (ratsnest length) remains a core metric for any placement engine.
